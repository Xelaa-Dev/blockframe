Block frame is a mod that brings gameplay elements of [Warframe](https://www.warframe.com/en) to minecraft like movement or weapons.![Double jump and roll example](https://xela.cloudflare-status.com/tm0RT9SDnI.gif)

## What does it add?
With time this mod will deliver elements of warframe gameply. I'm currently developing movement but in future it will include damage types and abilities.
Other warframe mods add bits and pieces of the game, this mod aims to add everything in a single package
## Features
- Double jump (2x space) (now without fall damage!)
- Roll (2x shift)
- Bleed / Slash damage from mobs (Configurable)
- Enchant your weapon with elemental and physical effects!
